# Evilauncher

Лаунчер, предназначенный для настройки и запуска игры "Проклятые земли" студии Nival.

Проект является духовным наследником EIStarter от GipatRu (https://www.gipath.org/forum/thread-2784.html).

# Ключевые возможности

Настройка всех ключевых параметров игры - пути к файлам, настройки графики, камеры

Поддержка тем оформления - каждый мод может показать собственный фасад

Поддержка переводов - локализация интерфейса программы

QoL фичи - информация о моде, версии аддона и т.д.

# Технические детали

.NET 8 C# (Windows Forms)

# Сторонние компоненты

ILMerge - (https://github.com/dotnet/ILMerge) утилита для объединения нескольких .NET-сборок в одну, упрощает распространение лаунчера.


Файлы для публичного релиза (графика, переводы, AddonDll) в данный репозиторий не входят.
